About

  
This page runs IBM MVS 3.8J on the Hercules System/370 emulator. Two terminals:
    Console is the MVS master console (device 0010; you see the IPL there and can type operator commands),
    TSO is a 3270 terminal for TSO (devices 0400-0403).

  
TSO user: MVSCE02, password PASS4U. At READY, type KICKS to start KICKS for TSO
    (try transaction INQ1 with customer 400001; leave with Clear, KSSF).
    CARDDEMO starts the CardDemo credit card application: sign on as USER0001 (or the administrator
    ADMIN001), password PASSWORD.

  
Download and Upload copy data sets between MVS and this computer with IND$FILE: log on, stay at
    READY, and the page types the command for you.

Reset machine?

  
This deletes the disks that are saved in this browser (your data sets, members, spool and logs)
    and starts again from the original MVS/CE system. It cannot be undone.

Start fresh?

  
The page saved your running machine and continued it when you came back. Start fresh discards that
    saved state, reloads the page and starts MVS again with an IPL. Your disks (data sets, members, spool) stay as
    they are now; the TSO session and the console messages end. To end TSO work cleanly, use Shut down first.
